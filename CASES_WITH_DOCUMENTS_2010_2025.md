## Detailed Analysis

### Document Availability Rate

Overall, only **12.4%** of cases filed since 2010 have downloadable documents. Here's why:

1. **PACER Costs**: Documents cost $0.10/page, limiting widespread access
2. **RECAP Coverage**: Relies on users donating purchased documents
3. **Sealed Documents**: Many documents are sealed by court order
4. **Case Types**: Some case types have higher sealing rates
5. **Electronic Filing Adoption**: Varies by court and case type

### Why Are Recent Years Declining?

The decline from 2019 (220k) to 2024 (156k) represents a **29% drop**. Possible reasons:

1. **COVID-19 Court Closures**: Reduced filings in 2020-2021
2. **Backlog Processing**: Recent cases may not be fully uploaded yet
3. **Changing RECAP Usage**: Potential decline in RECAP user donations
4. **Settlement Trends**: More cases settling before document filing
5. **Data Lag**: Recent documents may still be processing

### Case Type Insights

**Most Documented Case Types:**
- Civil Rights cases dominate (135k cases, 4.2%)
- Labor/Employment disputes well-represented (93k cases, 2.9%)
- IP cases moderately documented (83k cases, 2.6%)

**Patent Cases:**
- 32,509 patent cases have documents (1% of total)
- Out of ~156k total patent cases filed (2010-2025)
- **Document availability rate: ~21%** for patents (higher than average!)

**Why Patent Cases Have Higher Availability:**
- Often involve sophisticated parties who access PACER frequently
- Higher value disputes = more document scrutiny
- Law firms and researchers regularly monitor patent litigation
- Universities and companies track patent cases for competitive intelligence

## Query Methods

### Year-by-Year Query

```bash
# Example: Get 2023 cases with documents
curl "https://www.courtlistener.com/api/rest/v4/search/?type=r&filed_after=2023-01-01&filed_before=2023-12-31&available_only=true" | jq '.count'

# Result: 163,335
```

### By Case Type Query

```bash
# Example: Get patent cases with documents
curl "https://www.courtlistener.com/api/rest/v4/search/?type=r&filed_after=2010-01-01&nature_of_suit=830&available_only=true" | jq '.count'

# Result: 32,509
```

### Python Script for Custom Analysis

```python
import requests

def get_cases_with_documents(year=None, case_type=None):
    """
    Get count of cases with downloadable documents.

    Args:
        year: Specific year (e.g., 2023) or None for all years since 2010
        case_type: Nature of suit code (e.g., 830 for patent) or None

    Returns:
        Count of cases with at least one downloadable document
    """
    params = {
        "type": "r",
        "filed_after": f"{year}-01-01" if year else "2010-01-01",
        "available_only": "true"
    }

    if year:
        params["filed_before"] = f"{year}-12-31"

    if case_type:
        params["nature_of_suit"] = case_type

    response = requests.get(
        "https://www.courtlistener.com/api/rest/v4/search/",
        params=params
    )

    return response.json()['count']

# Examples
print(f"2023 cases with docs: {get_cases_with_documents(2023):,}")
print(f"Patent cases with docs (2010-2025): {get_cases_with_documents(case_type=830):,}")
print(f"2023 patent cases with docs: {get_cases_with_documents(2023, 830):,}")
```
